## 技术选型明细

### 桌面框架
| 选项 | 选型 | 理由 |
|------|------|------|
| 框架 | **Tauri 2** | Rust 原生，包体 ~10MB，比 Electron 轻 10 倍 |
| 前端 | **React 18 + TypeScript** | 生态最成熟，社区资源丰富 |
| 构建 | **Vite** | 快速 HMR，Tauri 官方推荐 |
| UI | **Tailwind CSS + shadcn/ui** | 原子化样式 + 高质量组件 |
| 状态管理 | **Zustand** | 轻量、TypeScript 友好、无模板代码 |

### Rust 核心
| 用途 | 选型 | 理由 |
|------|------|------|
| SSH 客户端 | **russh** | 纯 Rust 实现，无 C 依赖，交叉编译友好 |
| 密钥生成 | **x25519-dalek** | Curve25519 标准实现 |
| 数据库 | **sqlx** (SQLite) | 编译时查询检查，异步支持 |
| Keychain | **keyring-rs** | 跨平台系统密钥库抽象 |
| 安全擦除 | **zeroize** | 密钥内存安全释放 |
| 二维码 | **qrcode** crate | 客户端配置二维码 |
| 加密 | **ring / rustls** | 高性能密码学原语 |
| 异步 | **tokio** | Rust 异步标准 |

### P2 平台隧道（后期）
| 平台 | 技术 |
|------|------|
| macOS | Swift Helper + WireGuardKit (SPM) |
| Windows | embeddable-dll-service |
| Linux | wg / wg-quick / NetworkManager |
