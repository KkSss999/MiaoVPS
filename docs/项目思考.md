# MiaoVPS — 项目思考

> 最后更新：2026-07-29

## 产品愿景

> **让任何人购买一台 VPS 后，几分钟内建立属于自己的私人网络。**

不做另一个"连接按钮"的 VPN 客户端，而是成为**自带服务器部署能力的私人网络管理器**。

## 目标用户

自建 VPN 的个人用户——有隐私需求、有 VPS，但卡在 Linux 配置、密钥管理和设备维护上。

## 核心痛点

| 痛点 | 描述 |
|------|------|
| 不会配置 Linux | 不知道如何安装 WireGuard、开启 IP Forward、配置防火墙 |
| 不知道怎么处理密钥 | 公私钥生成、分发、存储全流程困惑 |
| 不知道怎么添加设备 | 每台设备都要手动改配置，容易出错 |
| 不知道连接为什么失败 | 缺乏状态诊断，无法定位问题 |
| 不敢维护防火墙 | 担心误操作导致服务器失联 |
| 换服务器后全部重来 | 配置无法迁移，节点绑定死 |

## 差异化定位

| 维度 | 普通 VPN 客户端 | MiaoVPS |
|------|----------------|---------|
| 服务器部署 | 手动 | 一键 SSH 初始化 |
| 密钥管理 | 需要了解 WireGuard | 自动生成，私钥不出客户端 |
| 添加设备 | 手动编辑 wg0.conf | 界面操作，自动分配 IP |
| 信任模型 | 依赖厂商服务 | 本地优先，无中心账户 |
| 配置迁移 | 不支持 | 可导出可替换 |

## 核心原则

1. **本地优先** — 数据存本地，不依赖任何中心化服务
2. **SSH 直连** — 不在服务器安装 Agent，一击到位
3. **密钥私有** — 私钥永不离开客户端设备
4. **配置可迁移** — 节点可替换，配置可备份
5. **无账户依赖** — 不需要注册、登录、订阅

## 开发阶段

| 阶段 | 目标 | 核心交付 |
|------|------|----------|
| P0 | 端到端验证 | 手动部署 + 官方客户端连成功 |
| P1 | 桌面端部署器 | 服务器管理 + 设备配置 + 导出 |
| P2 | macOS 一键连接 | 系统级隧道集成 |
| P3 | 产品化 | 多节点、故障切换、Kill Switch |
